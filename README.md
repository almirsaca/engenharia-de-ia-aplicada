# 🎓 Pós-Graduação: Engenharia de IA Aplicada

Este repositório reúne todos os códigos, anotações, práticas de laboratório e projetos desenvolvidos ao longo da minha especialização em Engenharia de Inteligência Artificial Aplicada. O objetivo é documentar minha evolução e aplicar conceitos avançados de LLMs, agentes autônomos, DevOps e arquitetura AI-First.
